# Тестовые сценарии RevitPlanningPlugin

## ТС-01: Подключение к API

| # | Шаг | Ожидаемый результат | Статус |
|---|------|---------------------|--------|
| 1 | Открыть плагин, перейти «Подключение» | Форма настроек отображена | — |
| 2 | Ввести корректный Base URL, API Key, нажать «Сохранить» | Статус: «Настройки сохранены» | — |
| 3 | Нажать «Проверить соединение» | Статус: «Соединение установлено» (зелёная полоса) | — |
| 4 | Указать неверный API Key, нажать «Проверить соединение» | Статус: «Ошибка авторизации» (красная полоса) | — |
| 5 | Указать несуществующий URL, нажать «Проверить» | Статус: «Сетевая ошибка» или «Таймаут» | — |

## ТС-02: Загрузка списка контуров

| # | Шаг | Ожидаемый результат |
|---|------|---------------------|
| 1 | Настроить подключение (ТС-01) | Соединение работает |
| 2 | Перейти «Контуры», нажать «Загрузить список» | Список контуров заполнен; статус: «Загружено N контуров» |
| 3 | Проверить отображение имени и площади каждого элемента | Данные корректны |

## ТС-03: Загрузка и визуализация контура

| # | Шаг | Ожидаемый результат |
|---|------|---------------------|
| 1 | Выбрать контур в списке | Кнопка «Загрузить выбранный контур» активна |
| 2 | Нажать «Загрузить выбранный контур» | Контур отрисован на активном виде Revit; информация отображена в карточке |
| 3 | Проверить корректность геометрии (линии замкнуты, масштаб правильный) | Контур замкнут, координаты совпадают с ожидаемыми |
| 4 | Загрузить контур с невалидной геометрией | Сообщения валидации отображены красным; генерация заблокирована |

## ТС-04: Генерация вариантов планировки

| # | Шаг | Ожидаемый результат |
|---|------|---------------------|
| 1 | Загрузить валидный контур (ТС-03) | Контур отображён |
| 2 | Перейти «Генерация», установить 3 варианта, мин. площадь 10 м² | Параметры применены |
| 3 | Нажать «Сгенерировать» | Прогресс-бар отображён; статус: «Генерация 3 вариантов…» |
| 4 | Дождаться результата | Статус: «Получено 3 варианта»; вкладка «Результаты» содержит 3 записи |

## ТС-05: Просмотр и сравнение вариантов

| # | Шаг | Ожидаемый результат |
|---|------|---------------------|
| 1 | Получить варианты (ТС-04) | Галерея вариантов заполнена |
| 2 | Выбрать вариант 1 | Предпросмотр отображён поверх контура; метрики показаны в правой панели |
| 3 | Переключиться на вариант 2 | Предыдущий предпросмотр удалён; новый отображён без дублирования |
| 4 | Сравнить метрики: S, полезная площадь, количество помещений, score | Значения различаются между вариантами |

## ТС-06: Применение варианта (разделители + помещения)

| # | Шаг | Ожидаемый результат |
|---|------|---------------------|
| 1 | Выбрать вариант, нажать «Применить (разделители)» | Room Separation Lines и Room-элементы созданы в модели |
| 2 | Проверить помещения в Schedule / Room Schedule | Помещения перечислены с именами и площадями |
| 3 | Применить другой вариант повторно | Предыдущие элементы удалены; новые созданы без дублирования |

## ТС-07: Применение варианта со стенами

| # | Шаг | Ожидаемый результат |
|---|------|---------------------|
| 1 | Выбрать вариант, нажать «Применить со стенами» | Стены и Room-элементы созданы |
| 2 | Проверить стены в 3D-виде | Стены расположены по линиям перегородок |

## ТС-08: Обработка ошибок

| # | Сценарий | Ожидаемый результат |
|---|----------|---------------------|
| 1 | Отключить интернет, запросить контуры | Сообщение: «Сетевая ошибка»; возможность повторить |
| 2 | Передать 401 от API | Сообщение: «Ошибка авторизации» |
| 3 | Передать 500 от API | Retry (до MaxRetries); затем сообщение: «HTTP 500» |
| 4 | Нажать «Отмена» во время генерации | Операция отменена; статус: «Отменено» |

## ТС-09: Валидация контура

| # | Контур | Ожидаемый результат |
|---|--------|---------------------|
| 1 | Незамкнутый (зазор > 1 мм) | Ошибка: «Контур не замкнут» |
| 2 | Менее 3 сегментов | Ошибка: «менее 3 сегментов» |
| 3 | Самопересечение | Ошибка: «Самопересечение» |
| 4 | Площадь < 1 м² | Ошибка: «Площадь слишком мала» |
| 5 | Обход по часовой стрелке | Предупреждение: «CW_ORIENTATION» |

## ТС-10: Тестирование Mock-клиента

| # | Шаг | Ожидаемый результат |
|---|------|---------------------|
| 1 | Подключить MockPlanningApiClient вместо реального | Плагин работает без внешнего API |
| 2 | Загрузить список → 3 демо-контура | Контуры «Прямоугольный», «Г-образный», «Сложный» |
| 3 | Загрузить каждый и провести ТС-04–ТС-07 | Все сценарии проходят на мок-данных |
